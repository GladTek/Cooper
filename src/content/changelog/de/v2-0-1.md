Dieses Release bringt Optimierungen für mehrsprachiges SEO, verbessert die Core Web Vitals und verstärkt die Sicherheit der Node.js-Laufzeitumgebung.

### 🚀 Performance
- **LCP-Optimierung des Ankündigungsbanners**: Beseitigung der clientseitigen Renderverzögerung beim Anzeigen des Banners, wodurch das Banner sofort im ersten Paint erscheint und die LCP-Renderverzögerung eliminiert wird.

### 🌐 Internationalisierung & SEO
- **Mehrsprachige `hreflang`-Links**: Automatische Erstellung von `rel="alternate" hreflang`-Links (einschließlich `x-default`) für alle lokalisierten Seiten.
- **Präfix-Kollision behoben**: Fehler im `LanguagePicker` behoben, durch den unlokalisierte Pfade (wie `/demo/*` und `/license`) fälschlicherweise als lokalisierte Routen behandelt wurden.
- **Dynamische Alternativlinks**: Korrekte Berechnung der verfügbaren Sprachen (`availableLangs`) für paginierte Blogseiten, Schlagwörter (Tags) und Changelog-Routen.

### 🛡️ Sicherheit & Abhängigkeiten
- **Node.js-Versionsbeschränkung**: Mindestanforderungen festgelegt (`>=22.23.4 <23.0.0 || >=24.22.1`) und `engine-strict=true` zum Schutz vor CVE-2026-111497 aktiviert.
- **CI-Aktualisierung**: GitHub Actions upload-artifact auf Version 7 für native Node 24-Unterstützung aktualisiert.
- **Astro Core**: Aktualisiert auf Astro 7.4.4.
