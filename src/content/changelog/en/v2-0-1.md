This release delivers multilingual SEO improvements, Core Web Vitals optimization, and security updates for Node.js runtime environments.

### 🚀 Performance
- **Announcement Banner LCP Optimization**: Removed the deferred client-side reveal delay on the announcement banner, rendering it in the initial paint to eliminate Largest Contentful Paint (LCP) render delay.

### 🌐 Internationalization & SEO
- **Multilingual `hreflang` Alternate Links**: Added automatic generation of `rel="alternate" hreflang` links (including `x-default`) across all localized pages and layout types.
- **Prefix Collision Fix**: Fixed a route collision issue in `LanguagePicker` where non-localized paths (such as `/demo/*` and `/license`) were misidentified as localized routes.
- **Dynamic Alternate Links**: Added accurate `availableLangs` calculation across paginated blog listings, tag pages, and changelog routes.

### 🛡️ Security & Dependencies
- **Node.js Engine Enforcement**: Configured engine restrictions (`>=22.23.4 <23.0.0 || >=24.22.1`) and `engine-strict=true` to address CVE-2026-111497.
- **CI Modernization**: Updated GitHub Actions upload artifacts action to v7 for native Node 24 support.
- **Astro Core**: Updated to Astro 7.4.4.
