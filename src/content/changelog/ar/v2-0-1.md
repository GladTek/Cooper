يقدم هذا الإصدار تحسينات أساسية لتهيئة محركات البحث متعددة اللغات، وتحسين مؤشرات أداء الويب الأساسية (Core Web Vitals)، وتعزيز أمان بيئات تشغيل Node.js.

### 🚀 الأداء
- **تسريع LCP لشريط الإعلانات**: إزالة تأخير العرض في جانب العميل ليتم رسم الشريط مباشرة مع أول ظهور للصفحة للقضاء على تأخير عرض عنصر المحتوى الأكبر (LCP).

### 🌐 التدويل ومحركات البحث (SEO)
- **روابط `hreflang` البديلة**: توليد تلقائي لروابط `rel="alternate" hreflang` (بما فيها `x-default`) عبر جميع الصفحات المترجمة وقوالب التخطيط.
- **إصلاح تداخل مسارات اللغات**: معالجة خلل في `LanguagePicker` كان يعتبر المسارات غير المترجمة (مثل `/demo/*` و`/license`) كمسارات مترجمة.
- **روابط بديلة ديناميكية**: دعم دقيق لحساب اللغات المتاحة لصفحات المقالات المرقمة، وصفحات الوسوم، وسجل التغييرات.

### 🛡️ الأمان والتبعيات
- **فرض إصدارات Node.js الآمنة**: تقييد المتطلبات الدنيا للبيئة (`>=22.23.4 <23.0.0 || >=24.22.1`) وتفعيل `engine-strict=true` لمعالجة الثغرة CVE-2026-111497.
- **تحديث إجراءات CI**: ترقية إجراء upload-artifact في GitHub Actions إلى الإصدار 7 للتوافق الكامل مع Node 24.
- **ترقية حزمة أسترو الأساسية**: التحديث إلى أسترو 7.4.4.
